## 5. Observations relevant to later tickets

These are facts only. The decisions belong to the map's other tickets.

1. **Google has not discovered the site or the GitHub account.** Bing has discovered the GitHub account and repositories, but not the site. The site has no sitemap and is not registered in either console. The only inbound link observed is the GitHub profile's `blog` field.
2. **A display name appears in Bing's title for the profile, and Perplexity repeats a display name from crates.io.** Both come from the profile metadata on GitHub and crates.io, not from the site. This conflicts with the map's "handle only" identity constraint, and only the owner can change it on those platforms.
3. **The repository `homepageUrl` is empty.** The site's own repository does not link to the site.
4. **Bing still lists the profile README repository `SairaDev02/SairaDev02` after it became private.**
5. **The site has no preview metadata at all:** no OG or Twitter tags, no image, no favicon and no canonical link.
6. **AI assistants learn about the projects from GitHub and crates.io, not from the site.** `llms.txt` exists, but no assistant that was checked cited it.
