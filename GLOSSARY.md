# SairaDev02 home page

The site presents the owner's public GitHub repositories as Assets: a sensor view of dithered terrain with one Asset per repository, above an asset board. Opening is the only action.

## Language

### Assets

**Asset**:
One public repository, as shown in the sensor view and on the board.
_Avoid_: disc, track, project (as a domain term)

**Sensor view**:
The 3D terrain picture with its Assets, tags, card and readouts.

**Asset board**:
The list of Assets below the view.
_Avoid_: track list, playlist

**Tag**:
An Asset's short label in the view, A-01 onwards, matching its board number.

**Card**:
The previewed Asset's details in the view.

### Acting

**Preview**:
An Asset shown in the card and brackets while it is pointed at, focused or first-tapped; it changes nothing else.
_Avoid_: hover (as a domain term)

**Open**:
Opening an Asset's repository in a new tab at the gesture.
_Avoid_: play, navigate

**Opened**:
An Asset opened during this visit.

**Blocked tab**:
An Open the browser refused; the Asset is not marked Opened.
_Avoid_: popup

### State and look

**Active** / **Dormant**:
An Asset is Active when its repository was pushed within the last 30 days, Dormant when not.

**Theme**:
System, Light (paper) or Dark (key black).
